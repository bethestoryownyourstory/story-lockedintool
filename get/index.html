Download for Android

Android 8 or newer · free download · updates itself

Lockedintool is on Android for now. Open this page on an Android phone to install it.

HOW TO INSTALL

  1. Tap Download for Android and open the file when it's done.
  2. If Android asks, allow your browser to install unknown apps, go back and tap Install.If Play Protect says it doesn't know the app, tap More details › Install anyway.
  3. Open Lockedintool and go down the setup screen: Allow display over other apps, turn on Lockedintool system actions, then Start Lockedintool.
  4. Tap Allow Lockedintool to update itself (one time) and Keep Lockedintool always on.From then on new versions install by themselves while your screen is off.
